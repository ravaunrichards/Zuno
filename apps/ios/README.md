# iOS client

SwiftUI source lives in `ZunoApp/`. The project specification in `project.yml` is intended for XcodeGen on macOS.

The current native screens implement tab navigation and a first pass of the ZUNO homepage. Authentication, API-backed content, media upload, LiveKit, and payment integrations remain separate work. An Xcode build and code-signing check must be run on macOS before a release is claimed.
